ARCHITECTURE OVERVIEW:
====================

Request Flow for OTP Login:
1. User sends identifier (email/phone)
2. OtpService generates 6-digit OTP
3. CacheService stores in Redis (5 min TTL)
4. EmailService/SmsService sends OTP
5. User enters OTP
6. OtpService verifies and finds/creates user
7. JWT token generated
8. LoginHistory recorded
9. User authenticated

Request Flow for Social Login:
1. User clicks "Login with Google/Facebook/Apple"
2. Redirected to OAuth provider
3. User grants permission
4. Callback to /auth/social/{provider}/callback
5. SocialAuthService finds or creates user
6. Social account linked
7. JWT token generated
8. LoginHistory recorded
9. Redirected to frontend with token
