INSTALLATION STEPS
==================

1. Install Dependencies (Already Done):
   npm install passport passport-google-oauth20 passport-facebook passport-apple 
   npm install passport-jwt jsonwebtoken redis bcryptjs otp-generator nodemailer 
   npm install twilio express-rate-limit express-session connect-redis validator 
   npm install @types/passport @types/passport-google-oauth20 @types/express-session 
   npm install @types/nodemailer

2. Set up Environment Variables:
   - Copy .env.example to .env
   - Fill in all credentials:
     * Database credentials
     * JWT secret
     * Redis connection
     * Email service (Gmail, SendGrid, etc.)
     * Twilio credentials for SMS
     * OAuth credentials (Google, Facebook, Apple)

3. Database Migration:
   npx prisma migrate dev --name add_passwordless_auth
   
   This will:
   - Create OTP table
   - Create SocialAccount table
   - Create TrustedDevice table
   - Create LoginHistory table
   - Add new fields to User table

4. Start Redis Server:
   On Windows with WSL: wsl redis-server
   Or use Docker: docker run -d -p 6379:6379 redis:latest

5. Run the application:
   npm run start:dev


API ENDPOINTS REFERENCE
======================

OTP-BASED AUTHENTICATION
-------------------------

1. Request OTP
   POST /auth/otp/request
   Body: {
     "identifier": "user@example.com" OR "+923001234567"
   }
   Response: {
     "success": true,
     "data": {
       "message": "OTP sent successfully to email",
       "identifier": "us***@example.com",
       "method": "email",
       "expiresIn": 300
     }
   }

2. Verify OTP
   POST /auth/otp/verify
   Body: {
     "identifier": "user@example.com",
     "otp": "123456",
     "name": "John Doe"  // Only for new users
   }
   Response: {
     "success": true,
     "data": {
       "user": {
         "id": "user-id",
         "displayName": "John Doe",
         "email": "user@example.com",
         "authMethods": ["email-otp"]
       },
       "token": "jwt-token",
       "expiresIn": 86400,
       "requiresVerification": false
     },
     "message": "Account created successfully"
   }

3. Resend OTP
   POST /auth/otp/resend
   Body: {
     "identifier": "user@example.com"
   }

4. Cancel OTP
   POST /auth/otp/cancel
   Body: {
     "identifier": "user@example.com"
   }

5. Check OTP Status
   POST /auth/otp/status
   Body: {
     "identifier": "user@example.com",
     "type": "email"
   }

SOCIAL AUTHENTICATION
----------------------

1. Google OAuth Login
   GET /auth/social/google
   (Redirects to Google consent screen)

2. Google OAuth Callback
   GET /auth/social/google/callback
   (Handled automatically by Passport, redirects to frontend with token)

3. Facebook OAuth Login
   GET /auth/social/facebook

4. Facebook OAuth Callback
   GET /auth/social/facebook/callback

5. Apple OAuth Login
   GET /auth/social/apple

6. Apple OAuth Callback
   GET /auth/social/apple/callback

7. Get Linked Social Accounts
   GET /auth/social/accounts
   Headers: { Authorization: "Bearer jwt-token" }

8. Link Social Account
   POST /auth/social/link/:provider
   Headers: { Authorization: "Bearer jwt-token" }

9. Unlink Social Account
   DELETE /auth/social/unlink/:provider
   Headers: { Authorization: "Bearer jwt-token" }

10. Get Available Auth Methods
    GET /auth/social/methods
    Headers: { Authorization: "Bearer jwt-token" }

SECURITY FEATURES IMPLEMENTED
=============================

1. OTP Rate Limiting:
   - Maximum 3 OTP requests per 15 minutes per identifier
   - Prevents brute force attacks

2. OTP Attempt Limiting:
   - Maximum 3 failed verification attempts
   - OTP gets deleted after exceeding attempts

3. Device Fingerprinting:
   - Tracks trusted devices
   - Can require verification for new devices
   - Stores device info (browser, OS, IP)

4. Login Audit Trail:
   - Records all login attempts
   - Stores method, timestamp, IP, location
   - Useful for security analytics

5. Social Account Linking:
   - Prevents account takeover via social providers
   - Links to existing accounts if email matches
   - Allows multiple auth methods per user

6. Redis-Based OTP Storage:
   - Fast OTP lookups
   - Automatic expiration
   - No database bloat

TROUBLESHOOTING
===============

1. Redis Connection Error:
   - Make sure Redis server is running
   - Check REDIS_URL or REDIS_HOST/PORT configuration
   - Test with: redis-cli ping

2. Email Not Sending:
   - Check EMAIL_USER and EMAIL_PASSWORD
   - For Gmail, use app-specific password (not regular password)
   - Check firewall/email provider restrictions

3. SMS Not Sending:
   - Verify Twilio credentials
   - Check phone number format (should be E.164)
   - Ensure Twilio account has credits

4. OAuth Not Working:
   - Verify client ID and secret are correct
   - Check callback URLs match provider settings exactly
   - Ensure frontend is on allowed origins

5. Database Migration Issues:
   - Make sure DATABASE_URL is set correctly
   - Check database is running and accessible
   - Run: npx prisma db push (if migrate doesn't work)

6. Type Errors:
   - Run: npm install @types/node --save-dev
   - Run: npm run build (to check for TypeScript errors)


FRONTEND INTEGRATION EXAMPLE
===========================

React hook for OTP login:

const useOtpLogin = () => {
  const [identifier, setIdentifier] = useState('');
  const [showOtpInput, setShowOtpInput] = useState(false);
  const [otp, setOtp] = useState('');
  const [name, setName] = useState('');
  const [loading, setLoading] = useState(false);

  const requestOtp = async () => {
    setLoading(true);
    try {
      const res = await fetch('/auth/otp/request', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ identifier })
      });
      const data = await res.json();
      if (data.success) setShowOtpInput(true);
    } finally {
      setLoading(false);
    }
  };

  const verifyOtp = async () => {
    setLoading(true);
    try {
      const res = await fetch('/auth/otp/verify', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ identifier, otp, name })
      });
      const data = await res.json();
      if (data.success) {
        localStorage.setItem('token', data.data.token);
        // Redirect to dashboard
      }
    } finally {
      setLoading(false);
    }
  };

  return { identifier, setIdentifier, requestOtp, showOtpInput, 
           otp, setOtp, verifyOtp, name, setName, loading };
};
