⚠️ 2. Set Up Third-Party Services
   Email Service:
   - Set up Gmail app-specific password OR
   - Set up SendGrid/AWS SES account
   - Configure EMAIL_USER, EMAIL_PASSWORD in .env

   SMS Service:
   - Create Twilio account at twilio.com
   - Get Account SID, Auth Token, and Phone Number
   - Configure TWILIO_* variables in .env

   Google OAuth:
   - Go to https://console.cloud.google.com/
   - Create new project
   - Enable Google+ API
   - Create OAuth credentials (Web application)
   - Set authorized redirect URI
   - Configure GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET

   Facebook OAuth:
   - Go to https://developers.facebook.com/
   - Create new app
   - Set up Facebook Login
   - Configure app ID and secret
   - Set authorized redirect URI
   - Configure FACEBOOK_CLIENT_ID and FACEBOOK_CLIENT_SECRET

   Apple OAuth:
   - Go to https://developer.apple.com/
   - Create Team ID
   - Create Service ID
   - Create private key
   - Configure APPLE_CLIENT_ID, APPLE_TEAM_ID, APPLE_KEY_ID, APPLE_PRIVATE_KEY

⚠️ 3. Set Up Redis
   - Install Redis locally or use Docker
   - Command: docker run -d -p 6379:6379 redis:latest

QUICK START CHECKLIST
====================

To get the system running quickly:

1. ✅ Code is complete - No changes needed

2. Create .env file with:
   - DATABASE_URL (required)
   - JWT_SECRET (required)
   - REDIS_URL (for OTP)
   - EMAIL credentials (for OTP emails)
   - TWILIO credentials (for SMS)
   - OAuth credentials (Google, Facebook, Apple)

3. Run database migration:
   npx prisma migrate dev --name add_passwordless_auth

4. Start Redis:
   docker run -d -p 6379:6379 redis:latest

5. Start application:
   npm run start:dev

6. Test OTP endpoint:
   curl -X POST http://localhost:3000/auth/otp/request \
     -H "Content-Type: application/json" \
     -d '{"identifier":"test@example.com"}'

7. Test OAuth:
   Visit: http://localhost:3000/auth/social/google
